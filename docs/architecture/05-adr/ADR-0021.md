# ADR-0021

Status: Accepted

## Context

Athena has developed an Assistant foundation containing:

- AssistantEngine
- AssistantPlanner
- CapabilityRegistry
- ActionRegistry
- Workflow models
- Quality validation
- Evidence context
- Workspace integration

A review was performed to determine whether future Assistant Engine
development requires a new architecture.

The review confirmed that the existing foundation already provides:

- intent understanding
- capability routing
- declarative actions
- workflow planning
- validation boundaries
- controlled execution boundaries
- workspace-aware context
- evidence-aware design

## Decision

The existing Assistant foundation is accepted as the architectural basis
for future Athena intelligence capabilities.

No replacement assistant architecture will be introduced.

Future work will extend existing boundaries.

The architecture flow is:

User Request
→ Workspace Service
→ Assistant Engine
→ Intent Detection
→ Capability Registry
→ Action Registry
→ Workflow Planning
→ Assistant Plan
→ Quality Validation
→ Controlled Execution Boundary
→ Evidence-backed Response

## Consequences

Positive:

- preserves architectural consistency
- avoids duplicate orchestration systems
- protects maintainability
- supports future capability growth

Negative:

- future features must align with existing boundaries

## Future Direction

A21 will formalize reusable capability/tool contracts.

A22 will mature controlled assistant workflows using the existing foundation.

The following remain intentionally deferred:

- autonomous agent systems
- multi-agent orchestration
- unrestricted tool execution
- hidden memory systems
- storing user knowledge inside model weights
